# Simple Flask Web Application

This repository contains a simple Flask web application that displays an image and a short description on the main page. The application is intended to be used as a base for further development and deployment on virtual machines.

## Requirements

To run this project, you need to have the following installed:

- Python 3.x
- pip
- Git

## Local Deployment

1. **Clone the repository:**
    
    `git clone <repository-url>`
    
2. **Navigate to the application directory:**
    
    `cd week-1/kateryna/app`
    
3. **Create and activate a virtual environment:**
    
    `python3 -m venv venv 
    source venv/bin/activate`
    
4. **Install the required dependencies:**
    
    `pip install -r requirements.txt`
    
5. **Run the application:**
    
    `python3 app.py`
    

## Validation and Testing

After starting the server, check your terminal for the local address.

1. Open a web browser and navigate to that URL.
    
2. Verify that the application loads successfully and displays the image and description.
