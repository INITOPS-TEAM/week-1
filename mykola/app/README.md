# Flask Web Application


## Description
This is a simple Flask web application that renders an HTML page with a heading and an image.

## Requirements
The application requires Python and Flask to run correctly.


## Project Structure
The project contains a Flask application file, HTML templates, static files for images, and a requirements file.

## How It Works
Flask handles the main route and renders an HTML template.  
The template displays a centered title and an image loaded from the static directory.
